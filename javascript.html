JavaScript (JS) adalah bahasa pemrograman tingkat tinggi yang digunakan untuk membuat halaman web interaktif dan dinamis di sisi klien (browser). Bersama dengan HTML dan CSS, JavaScript merupakan salah satu dari tiga pilar utama pengembangan web, yang memungkinkan penambahan fitur seperti animasi, validasi formulir, dan respons terhadap tindakan pengguna. Seiring waktu, JS telah berkembang untuk dapat berjalan di lingkungan lain, seperti server (backend), aplikasi seluler, dan desktop.
